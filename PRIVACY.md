# Политика конфиденциальности / Privacy Policy

**Facebook Reels Publisher** — программа, которой владелец Страницы Facebook
сам публикует ролики на **свои** Страницы через Graph API (Reels Publishing API).

- Программа работает только от имени владельца и только с Страницами, которыми
  он управляет. Посторонние люди в неё не входят и ничего ей не передают.
- Персональные данные пользователей Facebook не собираются, не хранятся,
  не продаются и никому не передаются.
- Хранится только то, что нужно для работы, и только на сервере владельца:
  токен доступа его Страницы (в файле настроек), список уже опубликованных
  роликов и времена публикаций — чтобы не выложить ролик дважды и не превысить
  лимит Facebook.
- Удаление данных: достаточно удалить программу с сервера и отозвать доступ
  приложения в настройках Facebook («Настройки и конфиденциальность» →
  «Интеграции для бизнеса»). Других копий данных нет.

Вопросы — через Issues этого репозитория:
https://github.com/sasha543359/postfacebookreels/issues

---

**Facebook Reels Publisher** is a tool a Facebook Page owner runs to publish
videos to **their own** Pages via the Graph API (Reels Publishing API).

- It acts only on behalf of its owner and only on Pages the owner manages.
  No other people sign in to it or provide data to it.
- It does not collect, store, sell or share personal data of Facebook users.
- The only data kept, on the owner's own server, is what the tool needs to work:
  the owner's Page access token (in its settings file), the list of already
  published videos and publication times — to avoid duplicates and stay within
  Facebook's rate limit.
- Data deletion: remove the tool from the server and revoke the app's access in
  Facebook ("Settings & privacy" → "Business integrations"). No other copies exist.
